Code Ink - Privacy Policy

Last updated: October 31, 2026

1. Introduction

Code Ink is an Android application that generates random programming-inspired phrases for tattoo inspiration. Your privacy is important to us.

2. Information Collection

Code Ink does not collect, request, or transmit personal information to the developer.

  • No registration or login is required.
  • No personal information is requested.
  • No location information is collected.
  • No advertising or analytics services are used.
  • No generated phrases are sent to developer-operated servers.

3. Clipboard and Sharing

The Copy feature uses Android clipboard functionality to copy a phrase selected by the user.

The Share feature opens Android's system sharing interface. If you choose another application to share a phrase, that application handles the information according to its own privacy policy.

4. Data Storage

Code Ink does not maintain user accounts or store generated phrases on developer-operated servers. Phrases are selected from a predefined collection included in the application.

5. Third-Party Services

Code Ink does not intentionally integrate advertising, analytics, or external data collection services. The application uses standard Android and AndroidX libraries.

6. Children's Privacy

Code Ink is not specifically designed to collect personal information from children and does not knowingly collect personal information from any user.

7. Data Security

The application does not transmit personal information to developer-operated servers.

8. Changes to This Privacy Policy

This Privacy Policy may be updated if the application's features or data practices change. Updated versions will be published at this URL.
